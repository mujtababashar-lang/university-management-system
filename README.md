# 🎓 University Management System

A Java-based University Management System developed using Apache NetBeans and Maven. This application provides a graphical interface for managing student records and performing basic student management operations.

## ✨ Features

- 🔐 **Login System** – User login interface.
- 📊 **Dashboard** – Main application dashboard.
- 👨‍🎓 **Student Records** – View and manage student information.
- ➕ **Add Student** – Add new student records.
- ✏️ **Update Student** – Modify existing student information.
- 🗑️ **Delete Student** – Remove student records.

## 🛠️ Technologies Used

- Java
- Apache NetBeans IDE
- Maven
- Java Swing (GUI, if applicable)

## 🚀 How to Run

1. Install Apache NetBeans IDE.
2. Open NetBeans.
3. Select File → Open Project.
4. Choose the University Management System project folder.
5. Wait for Maven dependencies to load.
6. Run the project.
